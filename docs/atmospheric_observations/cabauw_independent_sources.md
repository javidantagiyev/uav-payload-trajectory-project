Before using an independently obtained dataset, record: provider and product name, original filename, accession/version, source URL, access date, license, SHA-256, observation period, variable definitions, units, timestamp convention, aggregation interval, instrument history and quality flags. Record any field that cannot be established as unknown. Never represent an access request as a received dataset. Historical datasets at nonoverlapping sites permit descriptive comparisons, not attribution of differences to geography alone.
